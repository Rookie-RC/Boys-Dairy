# 隐私与安全

一句话：日记只存在你的手机里；唯一会联网的功能是可选的 AI 锐评，且只在你点下按钮时，把你能在预览里看到的提示词发给你选的那一家 AI 服务商（DeepSeek 或 Claude），另一家什么也收不到。

## 存储位置

全部在应用私有目录，应用本身不会写外部存储（备份文件除外，见下）。

| 内容 | 位置 | 形式 |
| --- | --- | --- |
| 战绩（时间、类型、时长、事前 / 事后心情、愉悦度、笔记） | Room 数据库 `databases/boysdairy.db` | **明文** SQLite，不加密 |
| PIN | DataStore `settings`（`files/datastore/settings.preferences_pb`） | 16 字节随机盐（Base64）+ `SHA-256(盐 ‖ PIN)`（十六进制）；不存 PIN 明文 |
| PIN 锁定记录 | DataStore `settings` | 连续错误次数、锁定截止时间、最后更新时间（均为毫秒时间戳） |
| 主题 | DataStore `settings` | `SYSTEM` / `LIGHT` / `DARK` |
| 备份提醒 | DataStore `settings`，键 `lastExportAt`、`backupReminderSnoozedUntil` | 上次成功导出的时间、首页备份提醒暂缓到何时（均为毫秒时间戳）；不是日记内容，不进备份，「清空所有战绩」也不动它们 |
| 所选 AI 服务商 | DataStore `settings`，键 `aiProvider` | `deepseek` / `claude`（默认 DeepSeek）；明文，不是秘密，也不进备份。模型和推理强度固定在代码里，不存储 |
| API Key（每家服务商一个槽：`api_key_deepseek`、`api_key_claude`） | DataStore `secure`（`files/datastore/secure.preferences_pb`，与 `settings` 分开） | Base64(`iv ‖ 密文 ‖ tag`)，AES-256/GCM 加密 |
| 加密 API Key 的密钥 | Android Keystore，别名 `boysdairy_claude_key`（最初为 Claude 的 Key 创建，现在两个槽共用，名字为兼容而保留） | AES-256 / GCM，不可导出；是否由硬件保护取决于设备 |
| 界面语言 | AppCompat 的 per-app locale（Android 13+ 由系统 `LocaleManager` 保存） | 不在 DataStore 里 |

应用不写日志，没有统计、崩溃上报或广告 SDK。云备份和设备迁移被关闭：`allowBackup="false"`、`fullBackupContent="false"`，`data_extraction_rules.xml` 把所有数据域都排除了。旧版本留下的单个 `claudeApiKeyBlob` 会在首次访问时原样搬进 Claude 槽并删除。卸载应用会删除数据库、DataStore 和 Keystore 里的密钥，所以卸载前请先导出备份。

## 会离开设备的东西

只有 **AI 锐评请求**，且同时满足：

- 你在 AI 锐评页点下了那个大按钮（`AiViewModel.analyze()` 是唯一的发送路径；展开预览不联网）；
- 你已经为**当前所选**服务商填了自己的 API Key。

数据只发给**当前所选**的服务商，别家收不到任何东西。你可以在设置的 AI 卡片，或 AI 页的「谁来锐评」里切换（默认 DeepSeek）；切换后下一次锐评才发往新的那家，另一家的 Key 仍加密留在本机，想删可以在设置里清除。

| 服务商 | 请求发往 | 公司所在地 |
| --- | --- | --- |
| DeepSeek（默认） | `POST https://api.deepseek.com/chat/completions` | 总部位于中国 |
| Claude | `api.anthropic.com`（官方 Anthropic Java SDK 的默认地址） | Anthropic 总部位于美国 |

数据到了服务商之后如何保存、保留多久、是否用于训练，由所选服务商自己的服务条款和隐私政策（以及其所在地的法律）决定，应用无法控制，请自行阅读。请求用的是你自己的 Key，费用和用量记在你自己的账号上。`INTERNET` 权限只为这一个功能存在，应用里没有别的联网代码。

### 发送的内容

请求里的提示词有两段，**预览会把两段都原样显示**：

1. **系统提示词**：固定的指令文本（角色、语气——随「温柔 / 狠狠」变化、输出结构、回复语言），不含你的数据。
2. **用户消息**：你的数据，由 `AiPromptBuilder` 生成：

| 部分 | 内容 | 条件 |
| --- | --- | --- |
| 日期 | 今天的日期和星期 | 总是 |
| 统计摘要 | 总条数（单人 / 双人）、近 7 / 30 天条数、距上次的天数、连续活跃天数、最长间隔天数、最近几条的平均间隔、平均时长、平均愉悦度、事前 / 事后心情的次数分布、最忙的星期几、最忙的时段（夜 / 早 / 午后 / 晚） | 总是 |
| 最近记录 | 至多 30 行，每行：日期、星期缩写、单人 / 双人、时长（分钟）、事前心情、事后心情、愉悦度 | 总是 |
| 笔记 | 最近的至多 20 条非空笔记，每条带日期，压成一行，超过 200 个字符会被截断 | **仅当**你在 AI 页打开了「把笔记也发给 AI」；**默认关闭** |

两家用同一套提示词。除提示词外，请求还带：固定的模型名和推理强度（当前值在 `AiProvider.spec`，不是用户设置）、`max_tokens` 等参数，以及放在请求头里的 API Key（DeepSeek 用 `Authorization: Bearer`，Claude 用 `x-api-key`；不进请求体、不写日志）。服务商的服务器必然能看到你的 IP 地址和常规 HTTP 头。

重试与重定向：DeepSeek 路径**不重试、不跟随重定向**（请求带着你的数据和 Key，不会被转去别处）；Claude 路径走官方 SDK，失败时最多自动重试 1 次，同一份数据因此可能发送两次。

### 不会发送的内容

PIN、盐、哈希；主题和语言等设置；行 id；每条记录的具体时刻（只有日期，时段只出现在统计里的汇总）；备份文件；未被选中的那家服务商的 Key；应用不会附加设备标识。笔记在你不打开开关时一个字也不会发。

### 自己核对

AI 页的「看看会发送什么」会原样展示本次将发送的**系统提示词和用户消息**，它们加起来就是发给 AI 的全部提示词；预览随开关实时刷新，且与点按钮后实际发送的内容出自同一份代码（`AiAnalysisService.previewPayload` 与 `analyze`）。

### 返回的内容

AI 的回复只放在内存里显示，不写入数据库；上锁、重启应用后就没了。只有你点「复制」时，回复文本才会进入系统剪贴板：剪贴板条目不带标签，并在 Android 13+ 标记为敏感（`EXTRA_IS_SENSITIVE`），系统不会在剪贴板预览里显示它；但之后谁能读剪贴板、输入法会不会把它记进剪贴板历史，就不在应用控制范围内了。DeepSeek 返回的思维链（`reasoning_content`）会被直接忽略，不显示也不保存。界面上附有免责提示（仅供一乐，不构成医疗建议）。

### 想让任何东西都不出门

不填 Key 即可；已经填了的，在设置里「清除 Key」。

## 永远不会离开设备的东西

除上一节列出的 AI 请求内容外，其余一切——PIN 及其哈希、锁定记录、整个数据库、设置——都不会被应用发送出去；API Key 只会以请求头的形式发给它所属的那一家服务商。「完整战报」页的图表、分布和成就都在本机现算，不存储，也不进 AI 提示词（提示词内容仍只有上表所列）。

## 清空所有战绩

设置 →「数据」里的「清空所有战绩」会删除数据库里的全部战绩：先确认一次，再要求输入当前 PIN（走 `LockManager.verifyPin`，输错同样计入 5 次 / 30 秒的锁定）。PIN、主题、语言、所选服务商和 API Key 都不受影响。输入的 PIN 只放在对话框的内存状态里，不保存、不打印。

删除是 SQLite 层面的 `DELETE`：数据库文件里被删记录所在的页不会被立即覆写，在被新数据复用之前，能读到应用私有目录的人（见下文「诚实的局限」）仍可能用取证工具恢复部分内容。想彻底清除，卸载应用（会删除整个数据库文件）。

## 备份文件

导出的是一个 UTF-8 JSON 文件（格式见 [ARCHITECTURE.md](ARCHITECTURE.md#备份格式)）：

- **包含**：所有战绩，笔记是**明文**；另有应用标识、格式版本和导出时间。
- **不包含**：PIN / 盐 / 哈希、API Key、任何设置、行 id。
- **没有加密**。它保存在你用系统文件选择器选的位置；如果那是云盘或同步文件夹，文件就会随之上传——这是你的选择，应用不会替你上传，也不会记住这个位置。用完请自行删除或妥善保管。
- 导入时文件只被读取，且有 20 MiB 上限；格式不对的文件整体被拒绝。
- 应用只记住**上次成功导出的时间**（不记位置、文件名），用于设置页的「上次导出」和首页的备份提醒：战绩 ≥ 10 条、且从没导出过或上次导出已超过 30 天时提醒，可暂缓 7 天。

## 屏幕与会话安全

- **自动上锁**：整个应用离开前台（`ProcessLifecycleOwner` `ON_STOP`）就上锁；系统文件选择器也会触发上锁，选完回来要重新输入 PIN。设置 →「安全」里还有「立刻上锁」，把手机递给别人前一键锁上。
- **会话清空**：上锁时，解锁后界面的所有 ViewModel 被销毁（未保存的打卡 / 修改表单、屏幕上的 AI 回复、进行中的 AI 请求都会消失）；锁住期间只有锁屏界面在组合树里。
- **导航状态**：打开「修改战绩」或「在这天补一条」时，路由参数（那条战绩的行 id、补记日期）和其他路由一样，会随导航状态进入系统为 Activity 保存的实例状态；表单内容（笔记、心情、时长等）从不写进去。战绩列表的搜索词和类型筛选只在内存里。
- **`FLAG_SECURE`（仅 release）**：禁止截屏 / 录屏，最近任务里不显示内容，对话框同样受保护。debug 构建关闭它，方便 `adb screencap`；所以不要把 debug 版当作安全版本使用。
- **防暴力破解**：连续错 5 次锁 30 秒，之后再给 5 次；锁定记录持久化，杀进程、重启不会重置，系统时间被往回拨会被识别并重新锁满 30 秒。

## 诚实的局限

- **4 位 PIN 只有 10000 种可能。** 它是防旁人随手翻看的门闩，不是加密：数据库没有用 PIN 加密。任何能读到应用私有目录的人（root、取证提取、debug 版的 `adb run-as`）都能直接读走日记，不需要 PIN。
- **盐也救不了 4 位数字。** 拿到 `settings` 文件的人，对 `SHA-256(盐 ‖ PIN)` 做离线穷举是瞬间的事（只有一轮哈希）。
- **界面上的锁定只限制在界面上猜。** 5 次 / 30 秒的节奏下，穷举全部 10000 个 PIN 最坏约需 17 小时。锁定倒计时用系统时间，把时间往后拨可以提前结束一次锁定。
- **有人看着你输入 PIN，或者你的手机已被解锁并交给了别人**，这些防不住。
- **API Key 的保护有限**：Keystore 里的密钥不要求用户认证，所以加密只能防住「离线拿到文件」，防不住同一设备上能以本应用身份运行代码的攻击者（root 等）。填 Key 时它会经过系统剪贴板和输入法，这两者不在应用控制范围内；两家服务商的 Key 保护方式相同。建议使用专门为此创建、设了额度上限的 Key。
- **`FLAG_SECURE` 防不了拿手机拍屏幕**，也挡不住已经 root 的环境绕过它。
- **备份和 AI 请求是你主动放出去的数据**：备份文件是明文，开了「发送笔记」后笔记原文会到达你所选的 AI 服务商。笔记里有不想让第三方看到的内容，就别开。
- 「伪装成计算器」只是降低被好奇的人点开的概率，别人在应用列表里看到的名字和图标是「Daily Calc」，没有任何计算功能。
