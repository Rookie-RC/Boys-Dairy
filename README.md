# Boys Dairy（Daily Calc）

一本藏在计算器里的私人小本本。

桌面上，它叫「Daily Calc」，图标是个计算器，看起来比你的待办清单还无聊；点开之后先要报 4 位暗号，里面记的是每一次「个人修行」：什么时候、一个人还是两个人、多久、心情怎样、爽到几分。再配上日历、战报、成就墙和一点毒舌点评，帮你看清自己的节奏，顺便笑一下。

> **用之前先看这三条**
>
> - **日记只存在这台手机里。** 没有账号、没有云同步，系统的云备份和换机搬家也带不走它。卸载应用、清除应用数据、忘了暗号，日记都会没了，谁也救不回来。
> - **唯一的后悔药是你自己导出的备份。** 隔一阵子就导出一次（首页也会提醒你），存到你放心的地方。
> - **平时完全不联网。** 唯一会联网的是可选的「AI 锐评」：你不点那个按钮，一个字节都不会发出去。

## 为什么伪装成计算器

因为有些事不需要全世界知道。别人扫一眼你的应用列表，只会看到一个平平无奇的计算器；真点开了，迎面是一个要暗号的锁屏，副标题还会一本正经地说「这只是个普通的计算器 🧮（才怪）」。锁屏不分男生版、女生版，永远是同一套中性的伪装文案，旁人看不出你用的是哪一版。

说实话：它没有任何计算功能，伪装只是降低被点开的概率，真正挡人的是后面的暗号。

## 能做什么

- **打卡**：点底栏中央的小飞机 ✈️，记下时间、「单人副本」还是「双人成行」、时长、事前 / 事后心情、愉悦度（1–10 分）和笔记。单人副本还能记一个关键词「今日老师」（女生版叫「今日灵感」），最近用过的一点就能复用。时长和愉悦度会换来一句吐槽。
- **首页**：距上次多少天（七档「冷却」文案）、连续天数提醒、近 7 / 30 天的次数和平均愉悦度；每天一张黄历风的「今日宜忌」，按你最近的节奏给出「忌 / 不宜 / 平 / 宜」，只劝不催；还有养生贴士和月历，点某一天就能看当天的战绩、修改，或者给那天补一条。
- **战绩**：所有记录按月分组，能按笔记或关键词搜索、按单人 / 双人筛选。点开任意一条就能修改，改错了、删错了都能撤销。
- **完整战报**：从首页进入，看总览、本月和上月对比、近 12 周走势、星期和时段分布、心情排行、「老师排行榜」，外加一面成就墙（保存时解锁了新成就会顺带告诉你）。全部在手机上现算。
- **AI 锐评**（可选）：用你自己的 API Key，让 DeepSeek（默认）或 Claude 看看你的战绩，再嘴上复盘一遍。「温柔哄哄」和「狠狠锐评」两档，结果可以一键复制。
- **备份与导入**：在设置 →「数据」里把所有战绩导出成一个文件，存哪由你决定；导入时可以「合并」（重复的自动跳过）或「覆盖」（清空后换成备份里的）。
- **暗号锁与指纹**：4 位暗号，切到别的应用就自动上锁；连续输错 5 次关 30 秒小黑屋，杀掉应用、重启手机也不清零。有指纹的手机可以在设置里打开指纹解锁。要把手机递给别人？设置里还有「立刻上锁」。
- **男生版 / 女生版**：第一次进门时选一次，界面口吻跟着换（男生版说「发射」「贤者时刻」，女生版说「放飞」「余韵时刻」），布局、配色、功能和数据完全一样。
- **看着顺眼**：白天（奶油色）和夜猫子（暗紫色）两套主题，中文 / English 随时切换，emoji 管够。

养生贴士、今日宜忌和 AI 锐评都是图一乐，不构成任何医疗建议。

## 隐私一览

一句话：日记只在你手机里；只有你点了 AI 锐评，才会把一份战绩摘要发给你选的那一家 AI。

- **日记只存在本机。** 不上传，没有账号，没有云同步；系统的云备份和换机搬家也被特意关掉了，不会把日记带去别处（也意味着它们帮不了你恢复，见开头的提醒）。
- **只有点了 AI 锐评的按钮才会联网**，而且只发给你选的那一家（DeepSeek 或 Claude），另一家什么也收不到。不填 Key，就什么都不会出门。
- **发出去的是统计摘要和最近至多 30 条精简记录**：日期、单人 / 双人、时长、心情、愉悦度。不含暗号、设置，也不含具体几点几分。
- **笔记默认不发。** 只有你在设置 →「AI」里打开「把笔记也发给 AI」，才会附上最近的笔记（每条截短）；这个开关会一直记住，不想发了随时关掉。
- **单人关键词（「今日老师 / 今日灵感」）永远不发**，打开笔记开关也不发。
- 数据到了 AI 服务商那里怎么保存、会不会拿去训练，由那家自己的条款说了算（DeepSeek 总部在中国，Claude 背后的 Anthropic 在美国），这个应用管不了。
- **AI 的回复只显示在屏幕上，不保存**，上锁就没了；只有你点「复制」，它才会进剪贴板。
- **API Key 加密后只存在这台手机上**，只在你点锐评时交给它所属的那一家。
- **暗号不存原文**，只存一串算出来的乱码。指纹比对由手机系统完成，应用碰不到你的指纹。
- **正式版禁止截屏和录屏**，最近任务里也看不到内容。
- **男生版 / 女生版只是本机的界面设置**：不进备份，也从不发给 AI。两版发给 AI 的内容一字不差，而且不涉及性别。
- **备份文件没有加密**，笔记和关键词都是明文。存进网盘，它就会跟着上传；放哪、留多久，你自己把关。备份里不含暗号、Key 和设置。
- **没有广告、统计、崩溃上报，也不写日志。**
- **实话实说：4 位暗号只有一万种组合**，防的是室友、朋友顺手翻看，不是专业取证。日记本身并没有用暗号加密，手机被 root（破解了系统权限）或者被专业工具提取数据时，它挡不住。

想看完整说明（存了什么、存在哪、发出去的每一项、已知局限）：[docs/PRIVACY.md](docs/PRIVACY.md)。

## 安装

- 需要 **Android 8.0 及以上**的手机。
- 目前**没有上架任何应用商店，也没有现成的安装包可以下载**。需要自己用电脑从源码构建、签名，再装到手机上（要一点动手能力，或者找个会的朋友帮忙），步骤见开发文档的「[装到自己手机上](docs/DEVELOPMENT.md#装到自己手机上)」。
- 日常使用请装**正式版**（release 版）。给开发调试用的版本没有防截屏保护，别拿它记真事。
- **以后升级要用同一把签名密钥构建**，否则手机会拒绝覆盖安装，只能卸载重装；从调试版换成正式版也是一样。而卸载会删掉全部日记，所以升级前先导出备份。
- 装好后在桌面找「Daily Calc」（计算器图标）。第一次打开：设 4 位暗号 → 再输一次确认 → 选男生版或女生版 → 开记。想用 AI 锐评，再去设置 →「AI」里选服务商、填 Key。

## 常见问题

### 忘了暗号怎么办？

没有找回功能，没有后门，也没有客服能帮你重置，这是故意的。

- 如果你开着指纹解锁、指纹也还能用：先用指纹进去，到设置 →「数据」把战绩导出来。（改暗号必须先输入当前暗号，所以没法直接改。）
- 然后在手机系统设置的应用信息里找到 Daily Calc，清除它的数据（各家手机叫法略有不同），或者干脆卸载重装。暗号、日记、设置和 Key 会一起清空，应用回到第一次打开的样子：重新设暗号，再把备份导入。
- 没开指纹、手上也没有备份的话，日记就找不回来了。所以：定期导出备份，暗号别用生日，也别忘了。

### 换手机怎么把日记带过去？

系统自带的换机搬家和云备份不会带上它（为了隐私特意关掉的）。在旧手机上到设置 →「数据」导出备份，把文件传到新手机；新手机装好应用、设好暗号后，在同一个地方导入就行（新手机上还没有战绩，选「合并」或「覆盖」都可以）。备份里只有战绩，暗号、主题、男女版、AI Key 这些要在新手机上重新设置。搬完记得把传输用的备份文件删掉或收好，它没有加密。

### AI 锐评要花钱吗？

应用本身不收钱，也没有广告和内购。AI 锐评用的是你自己在 DeepSeek 或 Anthropic（Claude）那里申请的 API Key，每次锐评按那家的价格计费，钱从你自己的账户里扣。建议专门为它建一个 Key，并在服务商那边设好额度上限。不想花钱、也不想联网，就别填 Key，其他功能照常用。

### 男生版和女生版有什么区别？

只有界面上的文字和一部分 emoji 不同：比如男生版的「发射」「贤者时刻」在女生版里是「放飞」「余韵时刻」，「今日老师」变成「今日灵感」。布局、配色、功能、数据一模一样，切换不会动你的战绩。第一次进门时选，之后可以在设置 →「外观」→「界面版本」里改（会再跟你确认一次）。它只是本机的界面设置，不进备份，也不会告诉 AI。

### 为什么截图、录屏是黑的？最近任务里也看不到内容？

故意的。正式版禁止截屏和录屏，免得日记跑进相册、云相册或者别人的屏幕共享里。（给开发调试用的版本没有这层保护。）

### 切出去一下，回来又要输暗号？

对，应用一离开前台就马上上锁，导出 / 导入备份时弹出的系统文件选择器也算。选完文件回来解锁一下，导出或导入会接着进行。

### 指纹解锁突然不能用了？

手机里新录了指纹（或者把指纹删光了），指纹解锁就会自动关掉，防止有人偷偷往你手机里加一枚自己的指纹。先用暗号进来，再到设置 →「安全」里重新打开就行。
